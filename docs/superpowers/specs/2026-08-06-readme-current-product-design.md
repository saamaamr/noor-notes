# Current-product README design

## Goal

Make the root README accurately describe the current Noor Notes interface,
working editor features, appearance controls, installation methods, privacy
model, and known package limitations.

## Structure

1. Lead with the native three-pane library and focused editor experience.
2. Group capabilities into Library, Editor, Appearance, Privacy, and Desktop
   integration rather than repeating overlapping feature bullets.
3. Keep source, Snap, and Flatpak installation paths distinct and explicit.
4. Repair the split Editor mode paragraph and keep Appearance as an independent
   section.
5. Document the five appearance choices, synchronized windows, adaptive
   symbolic icons, and persisted selection.
6. Preserve verified release checksums, data paths, sandbox limitations, and
   the statement that Store publication is not automated.

## Safety

The update changes documentation only. It does not alter the application,
database, package identity, release artifacts, or Snap Store state. Claims must
be supported by the current source, tests, or installation scripts. Features
