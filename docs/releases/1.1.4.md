# Noor Notes 1.1.4

Patch release after Snap stable 1.1.3 (revision 19), published on 2026-09-06 as stable and edge revision **23**.

## Changes

- Cohesive Snow/Midnight controls, compact settings, content-sized editor toolbars and mode-aware menus.
- Session-only editor margins now open below a compact Margins button, retaining Left, Right and Reset behavior.
- Separate Read-only windows remove hidden editor gaps and update their own reading insets when resized.
- Main and settings windows reopen safely after closing. Application-lifetime sticky ownership keeps surviving Read-only windows controllable after reopening the library.
- Failed cloud sync attempts no longer leave the UI permanently running or falsely report completion.
- Rust syntax remains compatible with the Snap's pinned compiler; no new package dependencies or note-storage migration.

## Scope

The default packaged build remains local-first. Live Supabase/Drive configuration is not newly embedded or enabled by this release. Provider sign-in and multi-device acceptance are not claimed verified by local HTTP fixtures. Existing local notes, formatting, autosave and encryption remain unchanged.

## Release gates

The Store cadence `hotfix` workflow computes stable patch + 1, builds one Snap, checks runtime ownership, runs Snapcraft lint, smoke-tests the package, publishes to edge and smoke-tests the Store-installed revision before stable promotion. GitHub downloadable assets remain separately versioned.

Local checks and Store publication evidence are recorded in `docs/ui-polish-verification.md`. Use `snap info noor-notes` to confirm the current channel.
