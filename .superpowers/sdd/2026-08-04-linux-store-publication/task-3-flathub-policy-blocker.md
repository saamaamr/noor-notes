# Flathub submission policy blocker — Task 3

Status: EXTERNAL BLOCKER

Flathub's current generative-AI policy prohibits AI-generated or AI-assisted
application content and prohibits AI-generated submission pull requests. This
store-publication plan explicitly assigns implementation to agentic workers, so
an agent must not create, automate, or open a Flathub submission PR for this
workstream.

The owner must determine whether the application's provenance can meet the
current policy before any human-led submission. This blocker does not prevent
local or hosted package validation, but it prevents an agent-driven Flathub
submission. No submission was attempted.
